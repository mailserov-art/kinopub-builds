# KinoPub для iPhone Duo

Готовые сборки (IPA) неофициального клиента [kino.pub](https://kino.pub) для iPhone. Исходного кода здесь нет — только сборки.

> ⚠️ **Приложение полностью оптимизировано под iPhone Duo и тестировалось только на нём.**
> На других iPhone оно может работать, но не проверялось.

Нужна подписка kino.pub. Вход по коду: приложение показывает код, вводите его на [kino.pub/device](https://kino.pub/device).

## Установка через AltStore (с автообновлениями)

1. Установите [AltStore](https://altstore.io) на iPhone.
2. AltStore → **Browse / Sources** → **+** → вставьте адрес источника:

   ```
   https://raw.githubusercontent.com/mailserov-art/kinopub-builds/main/apps.json
   ```

3. Откройте источник **KinoPub для iPhone Duo** → **KinoPub** → **Free / Install**.

Новые версии будут появляться в AltStore как обновления.

## Установка вручную

Скачайте последний `.ipa` из папки [`builds`](builds) и откройте его в AltStore (**My Apps → +**).
